## 三、训练层（第 2–3 周）

### 3.1 关键决策：用虚拟环境，别污染系统 Python
你系统 Python 是 3.12.10。**不要直接 `pip install tensorflow` 到系统环境** —— TensorFlow 依赖树很大，装崩了很难退。

推荐用 **venv**（内置）或 **uv**（更快）：
```powershell
cd F:\00_MK\TensorFlow
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
```
> 若 `Activate.ps1` 被执行策略拦住：
> ```powershell
> Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
> ```

### 3.2 训练框架：二选一（**别两个都装**）
| 框架 | 装它的理由 | 端侧注意 |
|---|---|---|
| **TensorFlow** | 与 TFLM 同源，转换链路最短，官方文档全 | ⭐ 走 TFLM 就选它 |
| **PyTorch** | 调试体验好，新模型多 | 端侧要经 ONNX/ExecuTorch 中转，多一道坎 |

**给你的建议：选 TensorFlow。** 你的目标是 TFLM，同源转换最省事。

```powershell
pip install tensorflow
```
> ⚠️ **Python 3.12 兼容性**：TensorFlow 2.16+ 才正式支持 3.12。若 `pip` 解析失败，退回 Python 3.11 建 venv。

### 3.3 必配的辅助库
```powershell
pip install numpy pandas matplotlib scikit-learn
# 音频方向加：
pip install librosa soundfile
# 图像方向加：
pip install pillow opencv-python
```
| 库 | 用途 |
|---|---|
| `numpy` | ✅ 你已有（但 venv 里要重装） |
| `pandas` | 传感器数据表处理，阶段 B 采集分析必备 |
| `matplotlib` | 看数据分布、训练曲线、混淆矩阵 |
| `scikit-learn` | 划分数据集、算指标、基线对比 |
| `librosa` / `soundfile` | 音频特征（MFCC、梅尔谱） |
| `pillow` / `opencv-python` | 图像预处理 |

### 3.4 量化专用工具（阶段 C）
TensorFlow 自带 TFLite 转换器，**不需额外装**。但可选：
```powershell
pip install tensorflow-model-optimization    # QAT（量化感知训练）要用
```
> 关于 `pip install tflite`：那是**第三方**轻量解释器，**不是给 MCU 用的**，也**不是** TFLM。除非要 PC 端快速验模型，否则不用装。
> PC 端要跑 `.tflite` 验证，正确选择是 `tflite-runtime` 或完整 `tensorflow`。

## 四、分析层（第 4 周起）

### 4.1 ⭐ Netron（优先级最高，建议第 1 周就装）
可视化 `.tflite` / `.onnx` 的**神器**。`.tflite` 是二进制，Netron 能直接把算子、张量 shape、量化参数全画出来。
```powershell
winget install --id Netron.Netron -e
# 或用便携版：https://github.com/lutzroeder/netron/releases
```
**为什么重要**：排查"算子不支持""scale 不对""shape 错位"这类问题，看它比看代码快十倍。

### 4.2 数据采集与标注（阶段 B）
| 工具 | 用途 | 备注 |
|---|---|---|
| PlatformIO Serial Monitor | 收串口数据 | ✅ 已有，够用起步 |
| **自写 Python 脚本 + pyserial** | 批量采数据存 CSV | 阶段 B 主力，最灵活 |
| `pip install pyserial` | 上述脚本的依赖 | — |
| **Label Studio** | 通用标注（图像/音频/文本） | 数据量大时用 |
| **Audacity** | 音频片段裁剪与听检 | 关键词识别方向 |
| **Edge Impulse 数据采集** | 手机当传感器上传 | 快速起步 |

> **建议**：阶段 B 先用 `pyserial` 自写采集脚本。它逼你想清楚"采样率、时间戳、类别平衡"这些真问题——正是端侧 AI 的核心能力。

### 4.3 硬件测量设备（阶段 D）
| 设备 | 用途 | 预算 |
|---|---|---|
| 万用表 | 基础电流测量 | 已有则够用 |

| **INA219 模块** | 高精度电流记录，可接 MCU | 进阶，做功耗曲线 |

> 阶段 D 的核心是"**会测量，而不是靠猜**"。先买 USB 电流表 + 逻辑分析仪，性价比最高。

## 八、环境坑备忘（都是实测或高频踩的）

| 坑 | 症状 | 处理 |
|---|---|---|
| **长路径未开** | 编译中途 `cannot open file`，报错位置误导性强 | 开 `LongPathsEnabled`，工具装浅路径 |
| **`platformio.ini` 带 BOM** | `MissingSectionHeaderError: File contains no section headers` | Windows PowerShell 5.1 的 `Set-Content -Encoding utf8` **会写 BOM**；VSCode 存盘别选 "UTF-8 with BOM"。修复见下 |
| **污染系统 Python** | 装崩依赖树难回退 | 用 venv，别直装系统环境 |
| **路径含空格/中文** | 部分构建工具失败 | 工程路径保持纯英文无空格（你现在的 `F:\00_MK\TensorFlow` 可以） |
| **USB 线是充电线** | 板子上电但无 COM 口 | 换数据线（踩坑率极高） |
| **USB-UART 驱动缺失** | 设备管理器有未知设备 | 装 CP2102 或 CH340 驱动 |
| **S3 接错 USB 口** | monitor 无输出 | S3 开发板常有 UART 口 + 原生 USB 口两个座，接错就没输出 |
| **WiFi 占内存** | `AllocateTensors` 莫名失败 | 推理实验先关 WiFi |
| **TensorFlow 版本与 TFLM 不匹配** | `schema version N other than supported M` | 换匹配的 TF 重转模型 |

### BOM 修复命令
```powershell
$p = 'platformio.ini'
$text = Get-Content $p -Raw -Encoding utf8
[System.IO.File]::WriteAllText($p, $text, (New-Object System.Text.UTF8Encoding($false)))
```
