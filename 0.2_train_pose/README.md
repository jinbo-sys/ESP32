# 0.2_train_pose - 自训练头部检测模型（个人场景定版）

只用自己摄像头采集的 90 张标注图从零训练的"个人专用头部检测器"，
灰度单通道输入，包含数据采集、标注、训练、int8 量化转换、摄像头推理完整闭环，
不依赖任何外部数据集（COCO 通用训练/微调链路已全部删除）。

## 目录结构

```
0.2_train_pose/
├── capture_self.py      # ① 采集：10s 倒计时后每秒 1 帧 × 30 帧 → self_captured/
├── annotate_self.py     # ② 标注：点击头中心 / n=无头 / u=撤销 → head_labels.csv
├── train_self.py        # ③ 训练：纯自采集数据从零训练灰度单通道模型（自包含）
├── convert_head.py      # ④ 转换：.keras → int8 .tflite（自采集帧校准，175 KB）
├── head_demo.py         # ⑤ 摄像头实时检测，双阈值跟踪画头圈
├── self_captured/       # 自采集帧（120 张）+ head_labels.csv（57 有头 / 63 无头）
└── models/
    ├── head_model_int8.tflite         # 定版 int8（旧种子1量化，实测验收，175 KB）
    ├── head_model_int8_backup.tflite  # 定版 int8 备份（其 keras 源已被覆盖，勿删）
    └── head_model_seed8.keras         # 种子8候选（分离度持平但背景响应偏高，未部署）
    # 注：head_model.keras 标准名空缺 → convert_head.py 拒跑，防止误覆盖定版 int8
```

## 方案要点（定版参数）

| 环节 | 做法 |
|---|---|
| 数据 | 90 张自采集帧：54 有头（正）+ 36 无头（负，教模型抑制置物架/风扇） |
| 正样本增强 | 60% 整帧补边（与推理一致）+ 40% 随机裁剪；50% 翻转；亮度/对比度/Gamma/噪声 |
| 标签 | 96×96 单通道热度图，固定 sigma=2.5 锐斑，只学中心点 |
| 损失 | 加权 MSE，正样本权重 ×401 |
| 网络 | Conv32→Pool→Conv64→Conv128→Conv64→Conv1(sigmoid)，输入 192×192×1 灰度 |
| 预处理 | 1280×720 补边成正方形再缩放（不压扁，人脸有效放大 1.56 倍） |
| 定位 | argmax 峰值 + 3×3 邻域亚像素重心 |
| 跟踪 | 局部窗口（±18%）搜索 + EMA 平滑 + 中位数初始化 + 30 帧失效重置 |
| 双阈值 | **初始化 0.65**（实测定版：0.68 过严锁不上脸，0.65 仍高于背景最高 0.57）/ **跟踪期 0.60**（背景阶梯：置物架 0.50、桌面杂物 0.57） |
| 画圈 | 椭圆轴 0.11W / 0.14H，Y 补偿 -0.04 |

## 踩坑记录（本项目最重要资产）

1. **热度图别让高斯大小编码目标尺寸**——会学成弥散大斑；固定锐斑只学中心
2. **BCE 不可用**——收敛卡 0.69，加权 MSE 稳定；小斑权重必须 ×400 级
3. **通用数据训不出个人场景**——早期 COCO 模型把置物架/风扇当头（响应 0.66 vs 脸 0.53），
   结论：负样本必须包含**用户自家环境**的无头帧才压得住（COCO 链路已删除，只留自训练）
4. **预处理必须与训练一致**——720p 直接压成 192×192 会横向压扁 1.78 倍，
   补边成正方形后脸部响应反超杂物，效果立竿见影
5. **单一硬阈值不可行**——脸分数波动大（0.47~0.93）与杂物重叠；
   解法是双阈值：严进（0.68 初始化）宽跟（0.60 跟踪；0.45/0.55 实测分别被
   置物架 0.50、桌面杂物 0.57 的背景响应长期滞留）。
   0.68 实测又过严——脸分数常落 0.6x 锁不上，终版定 0.65（严进宽跟语义
   自洽：初始化 0.65 > 跟踪 0.60 > 背景最高 0.57，且初始化仅搜画面中央
   +5 帧中位数，边缘杂物进不来），实测锁定稳定。
   **治本靠模型分离度**：弥散解（脸 0.66/背景 0.55）阈值怎么调都别扭，
   锐峰解（脸 0.93/背景低）阈值才从容——故 train_self.py 用多种子选优搜解域
6. **小数据从头训练可行**——90 张单一场景图 + 强增强，峰值响应 0.93，
   "过拟合到自己环境"正是个人检测器的目标
7. **微调不如重训干脆**——COCO+自采集微调版分数分离差（脸 0.80 vs 置物架 0.66），
   纯自采集重训后分离干净；COCO/微调脚本与备份模型已全部删除，只保留自训练一条链路

## 已知局限

- 只认识自家环境：换场景需补录数据重训（闭环已打通，约 10 分钟一轮）
- 转头侧面等未标注姿势可能跟丢：补录该姿势标注帧即可解决
- 同框多人时可能锁定到非目标人头

## 部署到 ESP32（下一步）

1. `xxd -i head_model_int8.tflite > model_data.cc` 生成 C 数组
2. TFLM `MicroInterpreter` 加载：输入 192×192×1 uint8 → 输出 96×96×1
3. 端侧预处理：灰度化 + 补边成正方形 + 缩放（与训练一致）
4. 后处理与 head_demo.py 一致（argmax + 亚像素 + 双阈值跟踪）
